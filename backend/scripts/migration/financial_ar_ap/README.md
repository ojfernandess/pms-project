Cópia de `supabase/migrations/202511181*.sql` para o image do backend.

**Ao alterar o domínio financeiro:** edite em `supabase/migrations/` e copie de volta para este diretório (ou rode `apply-financial-ar-ap.sh` apontando para `supabase/migrations` em dev).
