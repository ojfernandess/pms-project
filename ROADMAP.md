# 🗺️ Roadmap de Desenvolvimento - Innvator Core

## Visão Geral

Este roadmap apresenta as 5 funcionalidades principais a serem implementadas, com estimativas de tempo e prioridades.

---

## 📊 Quadro de Prioridades

| Funcionalidade | Prioridade | Estimativa | Status |
|---------------|------------|------------|--------|
| **1. Formulários de Reserva** | 🔴 Alta | 9-13h | ⏳ Pendente |
| **2. Tarifário Dinâmico** | 🟡 Média | 16-22h | ⏳ Pendente |
| **3. Módulo de Manutenção** | 🔴 Alta | 14-19h | ⏳ Pendente |
| **4. Relatórios Financeiros** | 🔴 Alta | 21-28h | ⏳ Pendente |
| **5. Channel Manager OTAs** | 🟡 Média | 12-16h (MVP) | ⏳ Pendente |

**Total Estimado (MVP):** 72-98 horas

---

## 🎯 Fase 1: MVP Essencial (4-6 semanas)

### ✅ Objetivos
- Sistema de reservas funcional
- Manutenção básica operacional
- Relatórios financeiros básicos

### 📋 Tarefas

#### Semana 1-2: Reservas
- [ ] Formulário de criação de reservas
- [ ] Integração com Supabase
- [ ] Validação de disponibilidade
- [ ] Listagem e filtros

#### Semana 3: Manutenção
- [ ] Interface de tickets
- [ ] Integração com status de quartos
- [ ] CRUD completo

#### Semana 4-5: Financeiro
- [ ] Gráficos básicos
- [ ] Relatórios principais
- [ ] Exportação de dados

---

## 🎯 Fase 2: Diferenciais (3-4 semanas)

### ✅ Objetivos
- Tarifário dinâmico
- Channel Manager básico

### 📋 Tarefas

#### Semana 6-7: Tarifário
- [ ] Sistema de temporadas
- [ ] Regras de precificação
- [ ] Promoções e descontos

#### Semana 8-9: Channel Manager
- [ ] Interface de configuração
- [ ] Sincronização manual
- [ ] Gestão de tarifas por canal

---

## 🎯 Fase 3: Avançado (Opcional)

### ✅ Objetivos
- Integrações reais com OTAs
- Funcionalidades avançadas
- Otimizações
